# Invitație Online la Spectacol 🎭

Aceasta este o pagină web modernă și responsive creată pentru a invita publicul la un spectacol special. Proiectul utilizează HTML și Tailwind CSS și este gândit să ofere o experiență vizuală plăcută și intuitivă.

## 🔍 Funcționalități

- Design responsive pentru desktop și mobil
- Fundal personalizabil cu imagine specifică evenimentului
- Titlu atractiv și mesaj de invitație
- Efecte vizuale elegante și animații simple
- Secțiuni tematice pentru:
  - Prezentarea spectacolului
  - Galerie foto cu actori sau momente din repetiții
  - Locație și oră
  - Informații de contact

## 🛠️ Tehnologii folosite

- HTML5
- Tailwind CSS
- Google Fonts
- Structură semantică și cod curat

## 📸 Cum folosești

1. Clonează proiectul sau descarcă fișierele.
2. Înlocuiește imaginile și textele cu informațiile despre spectacolul tău.
3. (Opțional) Poți adăuga un cronometru, un formular de confirmare sau un embed cu trailerul evenimentului.

## 📍 Exemplu de locație

Poți încorpora o locație Google Maps prin embed și link pentru orientare rapidă.
